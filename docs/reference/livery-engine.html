Ramp — thirteen steps

navylapizsky blue

Lightness steps evenly; hue bends through three anchors instead of two; chroma peaks around the core and tapers at both ends so neither end goes muddy or chalky.

Brightness is state

No second colour anywhere. Something is on when it rises up the ramp and off when it sinks toward the ground — how an annunciator panel actually works, and legible to anyone who can't separate red from green. Note that large areas take a lower rung than small marks: a lamp at the same brightness as the horizon line would burn a hole in the panel.

In Day, the ground is always cream — the livery only touches the light and the accents. A fully red or violet light mode is unreadable; a cream page lit by one is not.

One rig, six colours. Every livery now runs identical lighting — the same wide wash entering from just past the top-right, the same bloom and spread, the same fill sitting 140° from the key, the same glass and spill. The only thing that changes between them is the colour of the world itself. Pull any slider and it moves that livery off the shared rig; Reset to preset puts it back.
